Extract Stream

Get the direct audio/video stream URL by passing a song name or a YouTube link.

GET /api/v1?query={song_name}

Parameters:

  • query (Required): Song name or YouTube URL.
  • format (Optional): audio (default) or video.

Response (JSON):

{
  "success": true,
  "title": "Tum Se Hi Lyrical",
  "thumbnail": "https://i.ytimg.com/vi/.../hqdefault.jpg",
  "stream_url": "https://rr3---sn-npd.googlevideo.com/...",
  "client_used": "VIDSSAVE_BYPASS"
}

Why eDev API?

Unlike standard libraries (like ytdl-core or yt-dlp) that constantly get blocked on VPS servers, eDev API uses internal web bypassing. It requires NO Cookies and uses NO 3rd Party Proxies, making it 100% reliable.

Integration Guide

You can use the eDev API directly inside your Pyrogram or Telethon bots. Since the API returns a direct googlevideo.com URL, you can pass it straight to pytgcalls using AudioPiped, completely removing the need for yt-dlp.

import aiohttp
from pytgcalls.types import AudioPiped

# 1. Fetch from eDev API
async with aiohttp.ClientSession() as session:
    res = await session.get(f"https://edev.fun/api/v1?query={song_name}")
    data = await res.json()
    
# 2. Play the stream_url directly!
if data.get('success'):
    await call.join_group_call(
        chat_id,
        AudioPiped(data['stream_url'])
    )
